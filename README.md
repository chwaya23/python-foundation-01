# Python Foundation 01

A hands-on Python foundation project focused on building practical programming skills through small, progressively more complex exercises and automation-oriented problems.

This repository is part of my technical portfolio and represents the foundation of a broader progression toward **Python automation, APIs, infrastructure automation, and security automation**.

## 🎯 Objectives

The goal of this project is to develop strong Python fundamentals by writing code rather than only studying syntax.

Key objectives:

* Build confidence with Python syntax and programming logic
* Practice variables, data types, conditions, and loops
* Work with functions and modular code
* Handle files and directories
* Work with exceptions and input validation
* Practice data structures
* Write reusable Python code
* Introduce testing and debugging
* Begin thinking about automation problems programmatically

## 🧠 Concepts

The project will progressively cover:

| Area            | Concepts                                    |
| --------------- | ------------------------------------------- |
| Python Basics   | Variables, data types, operators            |
| Control Flow    | `if`, `elif`, `else`, loops                 |
| Functions       | Parameters, return values, scope            |
| Data Structures | Lists, tuples, dictionaries, sets           |
| Error Handling  | Exceptions, validation                      |
| Files           | Reading, writing, paths, directories        |

| Testing         | Unit tests and test-driven thinking         |
| Automation      | File operations, repetitive task automation |
| Git             | Commits, branches, repository management    |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd python-foundation-01
```

### 2. Create a virtual environment

```bash
python3 -m venv .venv
```

### 3. Activate the environment

```bash
source .venv/bin/activate
```

### 4. Verify Python

```bash
python --version
```

### 5. Run the project

Project-specific execution instructions will be added as functionality is developed.

## 📈 Development Approach

This project follows a **progressive learning approach**.

Rather than attempting to learn every Python feature at once, concepts are introduced, applied in small problems, revisited, and then combined into increasingly practical tasks.

The progression is roughly:

```text
Python Fundamentals
        ↓
Programming Logic
        ↓
Functions & Data Structures
        ↓
Files & Exceptions
        ↓
Modular Programs
        ↓
Testing
        ↓
Small Automation Tasks
        ↓
Larger Automation Projects
```

The intention is to continuously revisit earlier concepts while increasing the complexity of the problems being solved.
